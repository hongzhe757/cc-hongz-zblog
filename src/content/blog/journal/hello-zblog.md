这是迁到 **Astro** 后的第一篇。之后只需要在 `src/content/blog/` 下新增 Markdown 文件即可。

## 本地预览

```bash
npm run dev
```

浏览器打开终端提示的地址（一般是 `http://localhost:4321`）。

## 发布

推送到 `main` 后，GitHub Actions 会自动构建并发布到 GitHub Pages。自定义域名：`blog.hongz.cc`。
