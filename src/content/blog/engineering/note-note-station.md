# step 5: 下面说步骤

1.  下载手机app后
2.  note.crx插件一般在装note套件的时候，会有提示下载。否则自行下载。名称为note station clipper. crx
3.  将改插件该为zip后缀然后解压（因为浏览器有时候安装不上crx的插件，会报清单错误）
4.  选择解压后的html就行了。
5.  手机浏览器安装插件总体来说和电脑一样
6.  最后浏览网页的时候找到扩展插件，选择note插件即可。
7.  其他收藏网页插件nofox.com适用于谷歌或者其他浏览器书签不能同步时候。（插件方法安装一致）
8.  电脑端安装插件方法一致
