你好，cc-hongz-zblog

2026-11-08 · 起步

这是 cc-hongz-zblog 的第一篇。站点为纯静态 HTML，由 GitHub Pages 发布，自定义域名为 blog.hongz.cc。

日常写作

  1. 在 posts/ 新增一篇 .html（可参考本页）。
  2. 在根目录 index.html 的文章列表加一条链接。
  3. git push 后等待 Pages 更新。

以后若需要 Markdown 自动生成站点，可再迁到 Hugo / Astro，域名与仓库可不变。
